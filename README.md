# Supply Chain Analytics

An end-to-end analytics project on **inventory and supply chain data**, combining SQL analysis with interactive dashboards in **Tableau**, **Power BI** and **Excel**. The goal is to turn raw supply chain data into clear KPIs that help track inventory levels, sales performance, and operational efficiency.

---

## Project Objectives

- Analyze inventory and sales data to identify trends and bottlenecks
- Track key supply chain KPIs in a single view
- Compare dashboard approaches across Tableau, Power BI and Excel
- Support data-driven decisions on stock levels, demand and supplier performance

---

## Repository Contents

| File | Description |
|------|-------------|
| `Supply_Chain_Dataset.xlsx` | Raw dataset used for the entire analysis |
| `sql inventory and supply chain analysis.sql` | SQL queries for data exploration, cleaning and KPI calculation |
| `Inventory_sales.twbx` | Tableau workbook focused on inventory and sales analysis |
| `SUPPLY CHAIN DASHBOARD KPIs and charts.twbx` | Tableau dashboard with KPIs and charts |
| `Inventory & supply chain Dashboard.pbix` | Power BI interactive dashboard |
| `Inventory_Sales_Dashboard 1.xlsx` | Excel dashboard for inventory and sales |
| `Supply_Chain_Dashboard .xlsx` | Excel dashboard for supply chain KPIs |

---

## Tools & Technologies

- **SQL** – data querying and analysis
- **Tableau** – interactive dashboards (`.twbx`)
- **Power BI** – dashboard and DAX measures (`.pbix`)
- **Microsoft Excel** – dataset, pivot tables and dashboards

---

## Key KPIs Tracked

- Total sales and revenue
- Inventory levels and stock availability
- Stock turnover rate
- Order fulfillment / on-time delivery
- Lead time analysis
- Supplier and product-wise performance
- Regional / category-wise trends

---

## Analysis Workflow

1. **Data collection** – Supply chain dataset in Excel
2. **Data cleaning & exploration** – SQL queries to check quality and aggregate data
3. **KPI calculation** – SQL and calculated fields/measures
4. **Visualization** – Dashboards built in Tableau, Power BI and Excel
5. **Insights** – Findings that support inventory and supply decisions

---

## Key Insights

- Add insight 1 (e.g., which product categories have the highest sales)
- Add insight 2 (e.g., items with overstock or frequent stock-outs)
- Add insight 3 (e.g., suppliers with the longest lead times)

---

## How to Use

1. Clone or download this repository:
   ```bash
   git clone https://github.com/vishnupriya0488/Supply-Chain-Analytics.git
   ```
2. Open `Supply_Chain_Dataset.xlsx` to view the raw data.
3. Run the `.sql` file in your SQL environment to reproduce the analysis.
4. Open the `.twbx` files in **Tableau Desktop / Tableau Public**.
5. Open the `.pbix` file in **Power BI Desktop**.
6. Open the `.xlsx` dashboard files in **Microsoft Excel**.
